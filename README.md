# Data Visualization Portfolio

Data visualization portfolio showcasing user-centered design principles for civic data analysis. Created for the Data Analyst position with Innovate Memphis.

## Overview

This portfolio contains three professional work samples demonstrating ability to design user-facing data visualizations:

1. **Memphis Community Engagement Dashboard** - Civic metrics dashboard showing year-over-year trends
2. **Memphis Schools - Enrollment & Resource Distribution** - Education equity analysis with comparative metrics
3. **Memphis COVID-19 Vaccination Progress Tracker** - Public health dashboard with demographic breakdowns

## Design Principles

Each visualization demonstrates:
- ✅ **Clarity** - Simple, focused visualizations that answer specific questions
- ✅ **Accessibility** - WCAG 2.1 AA compliant (color contrast, ARIA labels, keyboard navigation)
- ✅ **Context** - Clear titles, labels, and annotations
- ✅ **Progressive Disclosure** - Key metrics highlighted, details available on interaction
- ✅ **User-Centered Design** - Tailored to stakeholder needs and decision-making contexts

## Viewing the Portfolio

Simply open `index.html` in a web browser to view all three visualization samples.

## Technologies Used

- HTML5 - Semantic markup with ARIA labels
- CSS3 - Responsive design, accessibility features, print styles
- No JavaScript dependencies - Pure HTML/CSS for maximum compatibility

## Accessibility Features

- WCAG 2.1 AA compliant color contrast ratios (minimum 4.5:1)
- Comprehensive ARIA labels and roles
- Keyboard navigation support
- Colorblind-friendly palettes (with text indicators)
- Responsive design for mobile devices
- Print-friendly styles
- Reduced motion support for users with vestibular disorders
