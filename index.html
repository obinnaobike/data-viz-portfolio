Data Visualization Portfolio

User-Centered Design for Civic Data Analysis

About This Portfolio

Welcome! This portfolio showcases three data visualization samples designed with user-centered principles. Each visualization demonstrates my ability to transform complex civic data into clear, accessible, and actionable insights for diverse audiences.

Design Principles Applied

  • Clarity: Simple, focused visualizations that answer specific questions
  • Accessibility: WCAG 2.1 AA compliant color contrast, ARIA labels, keyboard navigation
  • Context: Clear titles, labels, and annotations to aid understanding
  • Progressive Disclosure: Key metrics highlighted, details available on interaction

User-Centered Design Methodology

1. User Research

Identify stakeholder needs, technical literacy, and decision-making context

2. Data Simplification

Focus on key metrics that answer specific questions; avoid chart junk

3. Accessibility First

WCAG compliance, screen reader support, keyboard navigation, colorblind-friendly palettes

4. Iterative Testing

Test with actual users, gather feedback, refine based on comprehension and usability
